# Bookclub roadmap

The backlog lives on the [Bookclub backlog board](https://github.com/users/nickwolf/projects/2). Drag order on the board is the ranking, and each item carries a size. The open items are also listed by the [`backlog` label](https://github.com/nickwolf/bookclub/issues?q=is%3Aissue+is%3Aopen+label%3Abacklog).

This file links to the board rather than repeating it, so it can't go stale when something ships.

The implementation plans from July 2026 were retired when the backlog moved to issues. The issues that came out of them link back to the plan files at commit `4488538`.
